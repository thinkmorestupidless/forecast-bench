it resolves by, the time it closes and the time now. Write two search queries that would find the
news, data and analysis a forecaster needs to judge whether the question resolves yes.

Make the two queries different from each other and from the question's own words: one for the
latest reporting on the matter, one for the facts or figures the resolution criteria turn on. Each
query is a short line of plain words, as a person would type it into a search engine, with no
quotation marks and no operators.

Answer with one JSON object and nothing else:

{"queries": ["the first query", "the second query"]}
